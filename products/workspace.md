# Tsumugi Workspace

<div class="product-hero">
  <p>Tsumugi Workspace 是面向企业团队的统一协作工作区，将消息沟通、通讯录、待办、日志、企业应用和文件空间整合到一个可配置的工作台中。</p>
</div>

## 产品介绍

- 提供首次启动向导、企业管理员、登录会话与个人资料管理
- 支持单聊、群聊、群成员与群规则管理，消息可撤回、收藏并携带附件
- 管理联系人、部门层级和跨工作区联邦联系人
- 提供待办清单、全局搜索和操作日志，方便跟进任务与追溯变更
- 配置企业应用目录、工作台 Banner、应用分类与按部门可见范围
- 提供企业空间、个人空间、部门空间和群文件等存储空间

## 核心能力

| 能力 | 说明 |
| --- | --- |
| 协作沟通 | 消息、群聊、成员管理、公告、免打扰和附件发送。 |
| 组织管理 | 部门树、联系人归属、部门说明及企业管理员配置。 |
| 企业工作台 | 统一展示企业应用，支持分类、Logo、描述、预加载参数和部门权限。 |
| 文件空间 | 按企业、个人、部门和群组划分空间，记录容量配额与文件使用量。 |
| 任务与审计 | 待办创建、完成和删除；关键操作写入日志并支持搜索。 |
| 联邦协作 | 通过邀请和服务端地址连接外部工作区，交换联系人与消息。 |

## 技术与部署

- Go 服务端嵌入 React、Vite、TypeScript 前端，Vite 开发服务器通过 `/api` 代理后端
- 支持 SQLite、MySQL 和 PostgreSQL，通过 `TSUMUGI_DB_DRIVER`、`TSUMUGI_DB_DSN` 配置
- 首次访问自动进入 OOBE，创建企业管理员和登录账号；已配置工作区不会重复显示初始化页
- 生产构建前执行前端构建与 `go generate`，再启动 Go 服务统一提供控制台和 API

## 适用场景

适合需要统一内部沟通入口、企业应用门户和轻量任务协作的组织，也适合作为其他 Tsumugi 业务系统的统一工作台与身份入口。
