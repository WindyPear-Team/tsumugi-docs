# Tsumugi Pay

## 产品介绍

- 支持独立用户账户与支付工作区，平台管理员可统一管理用户状态
- 聚合支付宝、微信支付等官方通道，并支持同一服务商配置多个通道
- 提供账单中心、退款管理、审计日志和经营汇总看板
- 兼容 Open Payment Specification（OPS）发现、表单下单、接口下单、查询与异步通知语义
- 提供支付宝 RSA2、微信支付 API v3 验签与通知解密能力

## 核心能力

| 能力 | 说明 |
| --- | --- |
| 多用户运营 | 用户注册、OIDC 登录、角色权限、独立商户号与账户数据隔离。 |
| 订单与账单 | 支持待支付、已支付、关闭、失败及退款中等状态，并提供订单详情查询。 |
| 支付通道 | 管理支付宝和微信支付凭据、优先级、权重及启停状态；敏感凭据加密存储。 |
| 开放接口 | 提供 `submit.php`、`mapi.php`、订单查询接口和 OPS `.well-known` 发现地址。 |
| 回调安全 | 校验签名、商户订单号、金额和支付状态，支持回调去重与幂等状态推进。 |
| 运维审计 | 记录用户、资金和配置操作，支持站点、SMTP、hCaptcha 与 OIDC 设置。 |

## 技术与部署

- Go 服务端配合 GORM，支持 PostgreSQL、MySQL 8+ 和 SQLite
- React、Vite、TypeScript 管理后台；生产构建后由 Go `embed` 同源托管
- 首次启动向导会创建首位用户及其支付工作区，无需手动执行数据库迁移
- 生产环境应使用 HTTPS、强随机 JWT 密钥和独立的 32 字节数据加密密钥，并配置可公网访问的回调地址

## 适用场景

适合需要为多个业务账户提供统一支付运营后台、希望兼容传统易支付接口，或需要同时对接支付宝与微信官方 API 的 SaaS 平台。项目本身不提供收单资质、商户主体或生产密钥，正式接入前需完成服务商准入与验收。
