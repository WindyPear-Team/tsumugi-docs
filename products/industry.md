# Tsumugi Industry

<div class="product-hero">
  <p>Tsumugi Industry 是面向工业生产现场的控制与运营平台，将 PLC 数据、生产工单、流程定义和运营看板连接到统一的企业控制台，帮助团队建立可追踪、可扩展的生产执行闭环。</p>
</div>

## 产品介绍

- 提供首次初始化、用户、角色、细粒度权限和系统设置
- 管理设备、PLC 连接与协议中立的 PLC 变量目录
- 创建生产工单，按工序执行、报工、质检并记录生产事件
- 使用可视化流程编辑器编排生产逻辑，支持发布版本和运行实例控制
- 配置变量监控、历史采样、离线质量追踪和实时运营看板

## 核心能力

| 能力 | 说明 |
| --- | --- |
| PLC 与变量 | 将 `Pump001.Start` 等语义变量映射到具体 PLC 地址，隔离业务流程与底层驱动。 |
| 流程编排 | 支持 `SET`、`GET`、`WAIT`、`IF`、`DELAY`、人工确认、告警及暂停/恢复/取消控制。 |
| 生产工单 | 按顺序管理工序，支持操作员、PLC 或网关报工，并通过 `Idempotency-Key` 防止重复计数。 |
| 监控与看板 | 配置采样周期和保留天数，查看变量历史、设备状态与可视化经营指标。 |
| 安全与审计 | 对变量写入执行访问、范围、危险变量确认等校验，关键操作写入审计事件。 |

## 技术与部署

- Go、Gin、GORM 服务端，前端采用 React、Vite、TypeScript 与 shadcn/ui
- 数据库支持 SQLite、MySQL 和 PostgreSQL，通过环境变量选择驱动与连接串
- 服务端可嵌入生产构建后的前端，统一通过一个地址提供 API 与控制台
- 流程定义发布后不可直接修改，新版本创建后，运行中的实例仍固定使用原版本

## 适用场景

适合制造产线、设备联网、工艺流程控制和需要将现场报工与企业运营数据统一管理的团队。平台保留 PLC 驱动扩展边界，可从单条产线逐步扩展到多设备、多流程和多看板协同。
